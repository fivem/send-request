诊断手册 troubleshooting

        

          
常见失败原因与处理

          
    
            
  • 连接被拒绝 — 服务未启动或端口不对。先在终端确认 curl http://host:port/v1/models 是否返回 JSON。
    • 
            
  • CORS 报错 — vLLM 需加 --allowed-origins '*'；Ollama 需设置 OLLAMA_ORIGINS=* 后重启。浏览器直连受同源策略限制，命令行不受影响。
    • 
            
  • 404 Not Found — 路径前缀不匹配。尝试省略或追加 /v1，或改用 /api/tags（Ollama 原生）。
    • 
            
  • 401 / 403 — 服务启用了鉴权，请在 API Key 中填写令牌（Bearer Token）。
    • 
            
  • 混合内容被拦截 — 本页若以 https 打开，浏览器禁止请求 http 接口。请用本地文件打开或 http 页面。
    • 
            
  • 请求成功但无返回 — 模型正在加载权重，首次推理可能需数十秒，请调高超时时间。
